# MOBA Master

A 2D top-down **idle MOBA manager** game for Android, written in Kotlin.

> **Download:** grab the latest `MobaMaster.apk` from the [Releases](https://github.com/chook-games/moba-master/releases) page and install it on your Android device.

## Features

- Idle auto-battles — your team fights even while the app is closed
- Manage heroes, abilities and team composition
- Top-down 2D view
- Progression, upgrades and rewards

## Build

```bash
./gradlew assembleDebug
```

APK output: `app/build/outputs/apk/debug/app-debug.apk`.
